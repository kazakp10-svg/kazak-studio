# KAZAK studio

Локальная рабочая среда для фильма на Mac: сценарий, структура фильма (эпизоды, сцены, шоты), герои и места, кадры и дубли, библиотека и монтаж.

## Запуск

На Mac с macOS 12 или новее скачайте `KAZAK-studio-*.zip` из [GitHub Releases](https://github.com/kazakp10-svg/kazak-studio/releases) (для Apple silicon или Intel), распакуйте приложение в «Программы» и откройте его. Студия откроется в браузере по адресу <http://127.0.0.1:4317>; локальный сервер работает, пока приложение запущено. Значок K в строке меню позволяет снова открыть студию и проверить обновления.

Сборки пока не подписаны Developer ID и не прошли notarization, поэтому при первом запуске macOS откажется открыть приложение. Откройте «Системные настройки», «Конфиденциальность и безопасность», найдите сообщение о KAZAK studio и нажмите «Всё равно открыть». Это нужно один раз.

## Обновления

Приложение само проверяет GitHub Releases при запуске и раз в шесть часов. Когда выходит новая версия, появляется окно с описанием изменений и тремя кнопками: «Установить обновление», «Напомнить позже» и «Пропустить эту версию». Если вы согласились, приложение скачивает, проверяет, ставит версию и перезапускается само. Проекты, медиа и API-ключи лежат вне приложения и обновление переживают. Архивы релизов проверяются подписью Sparkle Ed25519.

## Выпуск новой версии

1. Поднимите версию: `npm version minor --no-git-tag-version`, допишите изменения в `CHANGELOG.md` под новым номером.
2. Закоммитьте, поставьте тег `v` и номер версии и отправьте его: `git tag v1.2.0 && git push origin main v1.2.0`.
3. GitHub Actions соберёт приложения для Apple silicon и Intel, создаст релиз, подпишет ленты обновлений и опубликует их на GitHub Pages. Пользователи получат предложение обновиться.

Закрытый ключ обновлений лежит в секрете `SPARKLE_PRIVATE_KEY`, открытый в переменной `SPARKLE_PUBLIC_KEY`. Резервная копия закрытого ключа нужна: без него выпустить обновление для уже установленных копий нельзя.

Для разработки нужен Node.js 22+ и Swift 6. Установите зависимости через `npm ci`; `npm start` запускает студию из исходного кода, `npm test` проверяет её, а `npm run build:app` собирает локальную оболочку.

## Словарь и структура

Во всём приложении слова значат одно и то же, как в кино:

- **Кадр** это одно изображение.
- **Шот** это видео. Его снимают из текста, из одного кадра или из двух: начального и конечного. Чем меньше опор, тем больше свободы у нейросети.
- **Дубль** это одна попытка снять шот. Лучший дубль выбирается для монтажа.
- **Сцена** состоит из шотов, **эпизод** из сцен, **фильм** из эпизодов. Для короткого ролика хватает сцен и шотов: эпизоды скрыты, пока второго нет.
- **Герои и места** это карточки с изображениями и описанием для постоянства персонажей и локаций.

Сцены это настоящие объекты, а не подписи. Заголовки сценария, которые начинаются с ИНТ., НАТ., INT., EXT. или СЦЕНА, сами становятся сценами; строки ЭПИЗОД и СЕРИЯ становятся эпизодами. Если переименовать заголовок в тексте, сцена и её шоты сохраняются. Переименование сцены в раскадровке меняет заголовок в сценарии. Сцену с шотами нельзя потерять случайно: она остаётся, даже если заголовок удалён. Можно создавать сцены и эпизоды и вручную, менять порядок кнопками, переносить шот в другую сцену списком в панели шота. Папки на диске называются по эпизоду, сцене и шоту и переименовываются вместе с ними. Фильмы, сохранённые в прежнем формате, где эпизод и сцена были текстом на шоте, открываются как структурированные; копия прежнего файла остаётся в `backups`.

Ассистент видит ту же структуру и тот же словарь.

## Первый фильм

1. Создайте фильм. В «Сценарии» добавьте текст, бриф и библию: персонажей, костюмы, свет и правила непрерывности. Слева появятся сцены. Выберите 16:9, 9:16 или 1:1.
2. В «Подключениях» добавьте ключи OpenAI, OpenRouter, BytePlus, DeepSeek и Anthropic. Пустое поле не меняет сохранённый ключ; новые значения хранятся в Связке ключей macOS.
3. В «Раскадровке» добавьте шоты в сцены. Кадры загружаются и создаются прямо в шоте. В «Героях и местах» соберите карточки персонажей и локаций. Выберите модель и способ: «Текст», «Кадр», «Начало и конец» или «Герои и места». Интерфейс показывает только то, что принимает модель.
4. Посмотрите предварительную оценку и запускайте генерацию. Задание и референсы сохраняются в истории; готовые файлы скачиваются на Mac и появляются среди кадров и дублей шота.
5. В «Монтаже» добавьте видео, задайте начало и конец, переставьте или разрежьте клип, отключите исходный звук при необходимости. Импортируйте музыку и выберите громкость. Экспорт создаёт MP4: H.264, AAC, 24 fps, 1080p. Кадры вписываются с полями, без обрезания изображения.

Сочетание ⌘S сохраняет текущий сценарий, шот или монтаж. Несохранённые изменения защищены предупреждением при уходе. «Предыдущая версия» восстанавливает предыдущий снимок проекта; повторное восстановление возвращает текущий снимок.

## Провайдеры и стоимость

- **OpenAI**: Responses API для сценария и промптов; Images API для генерации и редактирования. По умолчанию `gpt-6-sol` и `gpt-image-2.5-sunburst`. Имена моделей меняются в настройках под доступ аккаунта. Изображения GPT Image 2/2.5 создаются в пропорциях фильма, а старые модели — в поддерживаемом стандартном размере.
- **Seedance**: через OpenRouter или BytePlus ModelArk. В ModelArk для активации нужен доступный баланс Credits от $30 (сумма остаётся на балансе и списывается по использованию) либо план/пакет от $30.
- **Kling**: через OpenRouter или прямой Singapore API. Прямой Kling API принимает 5 или 10 секунд; его тариф и правила пакета проверьте в кабинете перед пополнением.
- **Соавтор**: OpenAI, DeepSeek, Claude API, Claude Sonnet CLI или Codex CLI. Выбор модели меняет доступные входы. CLI работает с подпиской пользователя; API использует настроенные ключи.

Перед запуском KAZAK показывает оценку цены. Seedance через OpenRouter считает видео по пикселям, длительности и тарифу модели; комиссия OpenRouter 5.5% применяется при покупке кредитов, а пополнение начинается от $5. Для 4 секунд Seedance 2.5 в 720p оценка около $0.98 с учётом комиссии; Seedance 2.0 — около $0.64. Итоговую стоимость и доступность подтверждает кабинет выбранного провайдера. Оценка — не счёт и может отличаться от фактического списания.

Ключ ModelArk сам по себе не активирует Seedance 2.0/2.5. По текущим условиям провайдера для активации нужен баланс Credits не менее $30, AI Savings Plan от $30 или ресурсный пакет от $30. Credits не имеют срока действия и могут покрывать другие сервисы BytePlus, но после покупки не возвращаются. После активации видео оплачивается по фактическому расходу токенов. Оценка в KAZAK — не счёт провайдера; итог смотрите в кабинете API.

Текст, выбранные изображения и параметры отправляются только указанному провайдеру после нажатия кнопки. Автоматического переноса ChatGPT Projects нет: импортируйте .txt/.md или вставьте сценарий. Ключ каждого провайдера подходит только к его маршруту.

## Сохранение, перенос и восстановление

На Mac данные находятся в `~/Library/Application Support/KAZAK studio API/data`: проекты в `studio.json`, исходники в `media`, экспорт в `exports`, предыдущие снимки в `backups`. Исходные файлы не перезаписываются. Состояние пишется через атомарную замену файла с синхронизацией на диск. На других ОС используется `.local` рядом с кодом.

В шапке проекта нажмите «Архив проекта»: архив .kazak включает сценарий, структуру фильма, шоты, историю с параметрами, карточки героев и мест, монтаж и **все медиа проекта**.

Лимиты: файл медиа до 1 ГБ, до 200 клипов в монтаже, до 500 шотов. Импорт архива до 2 ГБ в сжатом виде / 4 ГБ после распаковки. Для больших проектов сохраняйте копию всей папки `data`; архивирование требует дополнительного места на диске. Поддерживаются PNG, JPEG, WebP, MP4, MOV, WebM, WAV, MP3 и M4A. После импорта медиа проходят реальную проверку FFprobe.

При перезапуске видео с известным ID снова проверяются и скачиваются. Если отправка оборвалась до получения ID, студия пометит её «Нужна проверка» и **не повторит платный запрос**. Найдите ID в кабинете и укажите его в деталях задания. Ошибка скачивания повторяет скачивание готового результата. Текстовые/графические ответы, потерянные при перезапуске, требуют сверки истории провайдера. Незавершённый локальный экспорт запускается заново вручную.

## Ключи и локальный доступ

На macOS ключи хранятся в системной Связке ключей; проверяется чтение после сохранения. В браузер возвращаются только признаки наличия ключей. Хранилище привязано к папке данных; при переносе данных на другой Mac ключи вводятся заново. На других ОС резервный способ — локальный файл с правами 600; эта сборка ориентирована на Mac.

Сервер слушает только `127.0.0.1`, проверяет Host, Origin и заголовок приложения. Запросы с другого сайта блокируются. Медиа не публикуются в интернете. Ссылки результатов скачиваются через HTTPS, с проверкой публичного IP и перенаправлений. Страница не подключает внешние шрифты, аналитику или библиотеки.

## Проверено и ограничения

Автоматическая проверка покрывает создание и сохранение проекта, конфликт версий, восстановление, настоящий импорт медиа, адаптеры API на управляемых ответах, изображение и его редактирование, получение видео, MP4 с обрезкой/музыкой, порядок шотов, перенос архива и восстановление после перезапуска. Связка ключей проверена отдельным настоящим сохранением и чтением тестового значения. Вход в Codex CLI подтверждён; настоящий короткий ответ получен с моделью `gpt-5.5`. Модель CLI настраивается отдельно от модели OpenAI API.

Тесты используют управляемые ответы API и не тратят кредит пользователя. Перед первой платной генерацией проверьте ключ и выбранную модель; доступность и цена зависят от тарифа аккаунта.

Примеры архитектуры: [Concat](https://github.com/jub0t/concat), [Palmier Pro](https://github.com/palmier-io/palmier-pro); их код в приложение не включён.
